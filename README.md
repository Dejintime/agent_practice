# agent学习记录

## 第一章

学习了调用 API 生成文本、本地生成式大语言模型的文本生成、提示词工程，以及智能体的评估与调试。

主要内容：

- `chapter_1.ipynb`：调用 OpenAI API 生成文本。
- `chapter_2.ipynb`：使用 Transformers 加载本地模型，实现单轮和多轮对话。
- `chapter_3.ipynb`：学习角色扮演、思维链、上下文学习等提示词工程方法。
- `chapter_4.ipynb`：使用人工测试、基准数据集和大语言模型评估智能体。
- `chatbot.py`：本地多轮对话程序示例。

运行 Notebook 或 Python 程序前，需要先安装相关依赖，并根据本地环境修改模型路径和 API 配置。
